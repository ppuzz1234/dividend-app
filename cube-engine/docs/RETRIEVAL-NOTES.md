## ★ 하이브리드가 BM25 단독의 오답을 고쳤다

`"IRP 중도인출 사유"` 를 **BM25 단독**으로 돌리면:

```
1. RETIRE_D_14  확정기여형(DC)퇴직연금제도의 중도인출 사유   ← IRP 가 아니다
2. RETIRE_D_18  개인형퇴직연금(IRP)제도의 … 중도인출        ← 정답
```

**하이브리드(벡터 포함)로 돌리면 RETIRE_D_18 이 1위로 뒤집힌다.**

이건 세션 초반에 사람(나)이 저지를 뻔한 오인용과 **같은 실수**다 — "중도인출"로 검색해 DC 조문을 IRP 조문으로 인용할 뻔했고, 제목을 보고서야 잡았다. 어휘 매칭만으로는 `확정기여형` 과 `개인형` 의 차이를 못 가른다. 벡터가 의미 수준에서 그걸 구분한다.

**→ "reranker 왜 넣었어요?" 이전에 "벡터 왜 넣었어요?" 에 대한 답이 이 사례다.**

## ★ 정직한 발견 — 별칭의 가치는 벡터가 있으면 줄어든다

Phase 4 에서 별칭 사전을 만든 근거는 `ISA` · `IRP` 가 코퍼스에 **0건**이라는 실측이었다. 그런데:

| 조건 | 별칭 효과 |
|---|---|
| **BM25 단독 · 약어 단독 질의**(`"ISA"`) | 결과 **0건 → rank 1**. 결정적 |
| **BM25 단독 · 약어+맥락**(`"IRP 중도인출 사유"`) | rank 3 → 1. 개선 |
| **하이브리드**(위 표) | 대부분 **차이 없음** — 벡터가 이미 의미를 잡는다 |

즉 **별칭 사전은 BM25 절반을 살리는 장치이지 하이브리드 전체의 필수 부품은 아니다.**
그래도 유지하는 이유:
1. 벡터 임베딩이 약어에 강하다는 보장이 없다 — 이번 5개 질의에서 그랬을 뿐이다(표본 5).
2. `"ISA"` 같은 약어 단독 질의에서는 BM25 가 0점이라 융합 점수가 벡터 단독으로 퇴화한다.
3. Phase 6 평가셋이 이 주장을 버킷별로 다시 잰다. **표본 5개로 결론짓지 않는다.**
