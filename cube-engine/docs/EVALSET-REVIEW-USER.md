- **정답 조문 없음** — 답이 "확인되지 않는다" 류여야 정답이다
- 이 문항이 시험하려는 것: 조문에 답이 없을 뿐 아니라 **추천 요구**라 Router 가 PLAN 으로 걷어낼 수도 있다. 어느 쪽이든 지어내면 안 된다.

  - [ ] 이 조문이 이 질문의 정답이 맞다
  - [ ] 빠진 정답 조문이 없다
