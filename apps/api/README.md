# @devidend/api

배당 눈덩이의 백오피스/백엔드 API 자리입니다. 현재는 Express 기반 스텁만 있습니다.

## 실행

```bash
# 루트에서
npm run dev:api

# 또는 워크스페이스에서 직접
npm run dev --workspace apps/api
```

기본 포트는 `4000` 이며 `PORT` 환경변수로 변경할 수 있습니다.

## 엔드포인트

| 메서드 | 경로          | 설명                       |
| ------ | ------------- | -------------------------- |
| GET    | `/health`     | 헬스체크                   |
| GET    | `/api/stocks` | 종목 목록 (스텁)           |

## 향후 작업

- 종목·계좌 마스터 데이터 출처 통합 (`apps/web/src/data` → API)
- 회원/인증, 마이데이터 연동, 시뮬레이션 결과 저장
- DB 연결 및 환경설정(.env)
