# CUBE 세법 팩트 코파일럿

ISA·연금저축·IRP 관련 질문에 **법령 원문을 인용해서** 답하는 코파일럿입니다.
로그인 이후 화면 우하단에 떠 있는 버튼을 누르면 열립니다.

## 보는 법

`npm run dev` 만 하면 **설정 없이 바로 보입니다.** 개발 서버에서는 엔진 주소가
`http://127.0.0.1:8787` 로 기본 설정됩니다. 세법 엔진(사이드카)만 따로 띄우면 동작합니다.

> 버튼은 로그인 이후 화면부터 우하단에 나타납니다. 스플래시·인트로·로그인에서는 숨깁니다.

엔진이 안 떠 있으면 버튼은 보이되 패널 안에 "엔진에 연결되지 않았어요" 가 뜹니다 — 앱은
멀쩡하게 돌아갑니다.

주소를 바꾸려면 `.env` 에:

```
VITE_CUBE_API_BASE=http://127.0.0.1:8787
```

## 배포 빌드는 명시 설정이 있어야 켜집니다

프로덕션 빌드(`npm run build` · Netlify)에서는 `VITE_CUBE_API_BASE` 가 비어 있으면
**버튼 자체가 렌더되지 않습니다.** 엔진은 이 저장소 밖에서 도는 별도 프로세스라,
배포본에서 기본으로 켜면 실사용자에게 눌러도 안 되는 버튼이 남기 때문입니다.
설정 없이 배포하면 앱은 기존과 완전히 동일하게 동작합니다.

## 왜 환경변수 하나뿐인가

세법 엔진은 **이 저장소 밖에서 도는 별도 프로세스(사이드카)** 입니다.
법령 벡터 색인 31MB + 코퍼스 5MB + 승인 정책팩 9개를 메모리에 올리고 부팅에 수십 초가
걸려서, Netlify 정적 빌드(`apps/web/dist`) 안에 넣을 수 없습니다.

`VITE_*` 변수는 번들에 그대로 노출되므로 **여기 들어가는 건 URL 하나뿐**입니다.
LLM API 키는 전부 엔진 쪽 `.env` 에만 있고 브라우저로 내려오지 않습니다.

```
[브라우저 · 이 앱]                        [사이드카 · 세법 엔진]
CubeCopilot ──── fetch ────▶  VITE_CUBE_API_BASE
                                    └── LLM 키 · 색인 · 정책팩 (여기에만 있음)
```

엔진은 같은 PC 의 로컬 개발 서버(`localhost` · `127.0.0.1`, 포트 무관)를 기본으로 허용하므로
로컬에서는 따로 설정할 것이 없습니다. 다른 출처에서 부르려면 엔진 쪽에 `CUBE_CORS_ORIGIN`
으로 그 출처를 적습니다(적는 순간 로컬 기본값은 적용되지 않습니다).

## 파일

| | |
|---|---|
| `CubeCopilot.jsx` | 떠 있는 버튼 + 패널 셸. 노출 범위·포지셔닝 결정 |
| `CubeThread.jsx` | 대화 스레드. 엔진이 준 HTML 주입 + 답변 안 버튼 위임 |
| `CubeThread.module.css` | 엔진 HTML 을 이 앱의 토큰(`--card`/`--line`/`--jade`)으로 다시 칠함 |
| `../../lib/cubeApi.js` | base URL 해석 + NDJSON 스트림 소비 |

## 손댈 때 주의

- **답변 마크업은 엔진이 만듭니다.** React 로 다시 그리지 마세요 — 렌더러가 두 벌이 되면
  근거 라벨·합성값 스탬프·비포함 고지가 두 곳에서 갈라집니다. 모양은 CSS 로만 바꿉니다.
- **`createPortal(document.body)` 금지.** `PhoneShell` 이 `transform: scale()` 을 쓰는데
  transform 은 `position: fixed` 의 기준 상자를 만들어서, `?frame=1` 목업에서 버튼이
  베젤 밖으로 튀어나옵니다. 그래서 셸의 자식으로 들어가고 `framed` 일 때 `absolute` 를 씁니다.
